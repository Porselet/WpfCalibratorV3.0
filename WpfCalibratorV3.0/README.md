# Руководство оператора калибровочного программного комплекса WpfCalibrator v3.0

Настоящее руководство описывает порядок взаимодействия с интерфейсом и горячими клавишами калибровочного программного комплекса **WpfCalibrator v3.0** при работе с блоками управления на базе микроконтроллеров STM32 (BlackPill). Все операции ввода и передачи данных унифицированы и оптимизированы для исключения паразитной нагрузки на шину обмена UART.

---

## 1. Глобальная навигация и фокус ввода

Программный комплекс функционирует в бесфокусном режиме (интерактивный курсор Windows и фокус ввода внутри текстовых полей `TextBox` отключены), что предотвращает случайные сдвиги каретки и сбои форматирования данных.

* **`TAB`** — Циклическое переключение активного виджета на рабочем пространстве (холсте). Фокус активности автоматически распределяется **строго по калибровочным параметрам** (`IsParam == true`). Графики телеметрии (`TimePlot`) и индикаторы логов при навигации пропускаются.
* **`Клик левой кнопкой мыши`** — Принудительная активация выбранного виджета (скалярного параметра или таблицы) и отображение вокруг него рамки активности.

---

## 2. Управление двумерными таблицами (калибровками)

* **`Стрелки (Вверх / Вниз / Влево / Вправо)`** — Перемещение координатного указателя ячейки внутри активной 3D-матрицы.
* **`SHIFT + Стрелки`** — Множественное выделение прямоугольной области ячеек матрицы (групповой выбор) для одновременного редактирования диапазона калибровок.
* **`ПРОБЕЛ`** — Функция **«Jump to Working Point»** (Прыжок на рабочую точку). Мгновенное позиционирование координатного указателя на текущую режимную ячейку, подсвеченную зелёным цветом (фактическая рабочая точка ДВС по данным входящей телеметрии UART).

---

## 3. Редактирование значений параметров

### 3.1. Прямой ввод числовых значений с клавиатуры
1. Выберите целевой скалярный параметр или выделите область ячеек в таблице.
2. Начните ввод цифровых символов (`0..9`, `.`, `-`). 
3. Вводимый текст отображается **синхронно во всех выделенных ячейках диапазона**. На этапе набора данных шина обмена UART находится в состоянии покоя, фоновые обновления отладочного интерфейса не затирают вводимые символы.
4. **`ENTER`** — Фиксация и подтверждение ввода. Набранное число валидируется, зажимается в аппаратные лимиты `MinValue / MaxValue` и отправляется в микроконтроллер **строго одним залповым Bulk-пакетом групповой записи (`CMD: 0x01`)** для всей таблицы.
5. **`ESCAPE`** — Отмена текущего ввода. Буфер набора очищается, а редактируемые ячейки мгновенно восстанавливают исходные значения из оперативной памяти ПК.

### 3.2. Шаговое изменение параметров (Инкремент / Декремент)
* **`PageUp` / `PageDown`** — Изменение значения выбранного параметра или группы ячеек на величину стандартного шага, заданного в конфигурации виджета (`IncrementStep`).
* **`CTRL + PageUp` / `CTRL + PageDown`** — Ускоренное изменение параметров с десятикратным множителем шага (`IncrementStep * 10`).
* *Логика работы:* Если буфер ручного ввода пуст, шаг применяется к текущим физическим значениям в памяти. Если в текущий момент на экране производится ручной набор числа, шаг изменяет непосредственно текстовый буфер ввода.

## 4. Энергонезависимая фиксация данных (Запись во Flash)

* **Кнопка «💾 СОХРАНИТЬ ВО FLASH» (Левая навигационная панель)** — Формирует и отправляет в приоритетную очередь системного арбитра шины специализированный пакет управления:
  `[0xAA] [ModelId: 0x00] [Cmd: 0x03] [VarId: 0x00] [Len: 0x00] [CRC-8]`
  
  При получении данного кадра микроконтроллер STM32 приостанавливает циклы расчёта, копирует текущие калибровочные таблицы из ОЗУ в энергонезависимый сектор Flash-памяти (ПЗУ) устройства и восстанавливает обмен. Данная процедура гарантирует сохранение настроек после отключения питания блока управления.
